# Dashboard 功能清單

頂部按鈕對應的面板。「LIFF 對照」：有＝手機也能做；—＝刻意只在 Dashboard（原因見最後一節）。

| 面板（按鈕） | 功能 | LIFF 對照 |
|---|---|---|
| ＋新增活動／管理活動 | 建立與編輯活動（動態欄位、群組可見、火車班次、共乘／住宿開關、壇與資格）、活動管理者、啟用開關、刪除活動（連帶刪除報名等資料） | 有（event-admin.html） |
| 報名者管理（活動內） | 報名名單、搜尋、狀態、批次操作、刪除、即時更新 | 部分（LIFF 可看名單與改狀態） |
| 匯出（CSV／PDF／Excel） | 可新增自訂欄位、存成範本；Excel 開班參加名單可匯入範本（含公式）；自動排序（依性別及天職／依報名時間） | — |
| 任務管理 | 工作範本、子任務（分區、多人、時間／地點／負責人／檢核人）、預設（presets）、指派、即將到來（列表／月曆）、指派清單（可匯出）、工作管理者 | 有（tasks-admin.html） |
| 匯入 Word 工作細則／工作檢核表 | 從 Word／Excel 建立或更新工作範本 | — |
| 群組 | 系統與群組、群組成員 | 部分 |
| 流程表 | 開班課程表（日分頁、項目、預設）、流程管理者 | 有（activity-flow-admin.html） |
| 群聖家園連結 | 首頁連結與近期重要班程設定 | 部分 |
| 行事曆 | 行事曆事件管理、Word 匯入（同內容同時間略過）、依壇篩選 | 有（檢視；calendar.html） |
| 🚆 火車時刻 | 火車班次管理，供活動報名選擇 | — |
| 🕯 仙佛紀念日 | 農曆／國曆仙佛紀念日管理 | — |
| 成員資料 | 成員個人與親友資料、匯出 CSV | 有（profile.html，自己的資料） |
| 管理員角色／管理者權限 | 管理員角色、權限矩陣 | — |
| ⛩️ 壇 | 壇的新增與階層、各壇四組名單、各組工作細則（6W，可匯入）／交接項目／整組對調；天廚組的食譜／菜單／工作管理 | 有（altar-hub.html，對調由組長提出） |
| 🚗 共乘 | 車管理者名單、依活動的車次與需求媒合 | 有（carpool.html） |
| 🏠 住宿 | 住宿管理者名單、依活動的提供與需求媒合 | 有（lodging.html） |
| 🗣️ 溝通共識 | 會議管理員名單；會議類型、場次（出席／紀錄／待辦）、待辦事項總覽、統計與匯出 Excel／CSV（直接寫資料庫） | 有（meetings.html；無匯出） |

- 🤖 自動派工：規則（關鍵字／指定項目／仙佛紀念日／初一十五）、提前週數／天數、報名表範本、工作清單、群組、LINE 推送；預覽、立即執行、派工紀錄。

## 刻意只在 Dashboard 的功能
管理者角色與權限、Word／Excel 匯入、CSV／PDF／Excel 匯出、報名者批次管理、火車時刻、仙佛紀念日管理——這些是管理員在電腦上的批次或設定工作，手機上不實用。
